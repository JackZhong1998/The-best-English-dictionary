词头参考 [JavaProgrammerLB/cet-word-list](https://github.com/JavaProgrammerLB/cet-word-list) 的 [word-list.txt](https://github.com/JavaProgrammerLB/cet-word-list/blob/master/word-list.txt)。该仓库 README 说明其词表整理自《全国大学英语四、六级考试大纲（2016年修订版）》，仓库标注 MIT 许可。本批仅参考词头；义项选择、释义、例句、搭配和辨析均在本项目独立撰写。候选词条没有宣称经过官方考纲逐词核验。

本批 `etymology` 和 `semantic_shift` 保留空字符串，等待逐词查证。不要把词形相同当作词源相同，也不要根据拼写猜词根。

## 独立复核重点

- **可能涉及不同词源的同形词**：arm（手臂／武器）、bank（金融机构／河岸）、bear（熊／承受等动词）、bill（账单、纸币、法案／鸟嘴）。先核词源，再决定能否写统一的词义迁移说明。
- **不同词性或固定搭配**：account for 的“解释／占比”已拆义；aim at / aim for、appeal to / 法律上的 appeal、blow up 的爆炸义需逐一核对例句与中文。
- **美音与拼写**：average 的非重读音节可能弱化；answer 的 w 不发音；admit 的医院例句统一为美式 `to the hospital`。实际词头音频仍须逐词听检，不能仅凭 IPA 判断。
- **语境边界**：act 的法律名词、bar 的“障碍”、attack 的疾病发作、bill 的“鸟嘴”频率低于各词首义；复核时确认它们仍在目标读者的常用阅读范围内。
